# Hi, I'm Hari 👋

I'm a shipbuilder with some hands-on experience in basic ship design, and I write code.
I'm trying to get good at both.

## ⚓ In the shipyard

Ships are some of the biggest and most complicated things people build. Steel plates, welds,
pipes, cables and thousands of parts all have to come together in the right order, to the right
tolerance, on schedule. My work is building ships, and I've also done some basic design work, which helps
me see how a ship goes from drawing to steel. Along the way I've learned:

- **Respect for details.** One small mistake in a drawing or a measurement can cost days later on.
- **Thinking in systems.** A hull, its machinery and its piping only work as one connected whole.
- **Learning from people on the floor.** Some of the best engineering knowledge isn't written down
  anywhere.

## 💻 In programming

Computers fascinate me. It still feels a little like magic that a few simple operations —
add, compare, jump, repeat — can build up into everything a computer does. I like asking *how*
things really work underneath: how code becomes instructions, how memory is organised, and why
some problems are easy to compute while others are hard.

Right now I'm:

- 🧠 learning the fundamentals of computation and how computers work from the bottom up
- 🛠️ building small projects to practise what I learn
- 🔗 looking for ways to bring programming into shipbuilding, where so much is still done by hand

## 🌱 The idea

Shipbuilding and programming have more in common than they seem. Both are about turning a design
into something real, one careful step at a time. I'm still learning both, and I'm enjoying the
process.
